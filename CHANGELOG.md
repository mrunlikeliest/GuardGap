# Changelog

All notable user-facing changes will be recorded here. This project follows
[Semantic Versioning](https://semver.org/) once a stable public API is declared.

## 0.1.0 — Initial open-source release

- Self-hosted FastAPI dashboard with SQLite and PostgreSQL support.
- Scoped, revocable collector tokens and immutable evidence history.
- Python AST, saved Terraform plan, GCP, build, and named JUnit evidence adapters.
- Nine deterministic controls for Cloud Run, project IAM, Cloud SQL, Cloud
  Storage, and negative authorization testing.
- JSON, Markdown, and SARIF reports with optional pipeline gating.
- Architecture explorer with evidence-backed relationships.
- Before/after comparison, stale-evidence handling, audit history, and fixture demo.
- Docker, Compose, VM, Caddy, Cloud Run Terraform, and GitHub Actions examples.
- End-to-end showcase package with screenshots and reproducible evidence artifacts.
